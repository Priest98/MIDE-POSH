# MipeModish — Luxury Bespoke & Bridal Fashion

MipeModish is an artisan atelier web application showcasing bespoke bridal and luxury signature pieces from Lagos, Nigeria.

View your app in AI Studio: https://ai.studio/apps/3d22882c-9b67-4dd3-8e87-781f07fffc0d

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. Set the `GEMINI_API_KEY` in [.env.local](.env.local) to your Gemini API key
3. Run the app:
   `npm run dev`
